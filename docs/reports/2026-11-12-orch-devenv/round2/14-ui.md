# 14 · Agent window UI: visual and interaction defects (round 2)

Branch `e2e2/ui` (worktree `volt-e2e-ui`), base `81563ca39e4`. Written as the work went; the
final state is at the end of each section.

## Summary

- The five defects listed in the round-1 README are fixed, each reproduced first in a live dev
  window: Orbit labels over the project bar, the live status phrases overlapping
  ("ToolSearch"/"Thinking"), the stray "–"/"=" glyph (the message rail with nothing to go to), the
  project picker's mid-word path cut, and the yellow "Sandbox is partial here" notice.
- "Sandbox is partial here" was shown in every sandboxed chat because macOS can never enforce
  `process.tree` (no PID namespace). That is true but nobody can act on it, so the chat no longer
  says it; the only partial dimension the chat still mentions is `platform.tcc` (a project under
  Desktop/Documents/Downloads/iCloud/a volume runs under Volt's privacy permissions), quietly and
  with the fix. It used to print the raw id `platform.tcc`.
- Found while reproducing: four "Blocked by the sandbox" cards at the start of every new sandboxed
  chat (Claude Code's plugin sync from claude.ai); now housekeeping (still denied, not shown).
- Measured: status-swap overlap 5.4 px worst (4 of 22 sampled frames) → 0; status-to-timer gap
  after a swap 81 px → 8 px.

  20 ms of a swap, with the real stylesheet).
- Load during the live turns: 13–30 (five agents ran at once). `uptime` is in each run's folder.
