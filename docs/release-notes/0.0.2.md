This is the first Volt build you can download for macOS, Windows and Linux. It collects the work since the `0.0.1` tag: multi-agent tools, a code index for agents, design mode in the in-app browser, Git views for branches and worktrees, and a lot of speed work.

## Highlights

- **Design mode in the in-app browser.** Click an element or drag an area and tell the agent what to change. A pick is named after its React or Vue component and goes with a picture of what you chose. **Batch edits** holds several annotations as numbered pins and sends them together.
- **Subagents you can steer.** Resume a stopped subagent, retry a failed one, and see what each one changed in the turn's review.
- **Plan mode with a plan card.** An agent proposes a plan you approve, revise, edit or save, and can carry it out in a new worktree chat.
- **A code index for agents.** Volt indexes your open projects in the background, so `grep`, `glob`, `find_symbol` and `instant_grep` answer from an index.
- **Several Claude accounts.** Switch by hand, or let Volt move to another account near a limit.
- **Git views.** Branches, Remotes, Tags and Worktrees in Source Control, beside Commits and Stashes.
- **Faster.** Near-instant chat switching, bounded chat memory, and a shorter loop for small requests.

The full list is in the [changelog](https://github.com/LeulAria/volt/blob/v0.0.2/CHANGELOG.md#002---2026-10-18).

## Install

| Your computer | Download |
| --- | --- |
| Mac with Apple silicon (M1 and newer) | `volt-stable-0.0.2-darwin-arm64.dmg` |
| Mac with an Intel chip | `volt-stable-0.0.2-darwin-x64.dmg` |
| Windows (x64, or Arm) | `volt-stable-0.0.2-win32-<arch>-user-setup.exe` |
| Linux | `volt-stable-0.0.2-linux-<arch>.deb`, `.rpm` or `.tar.gz` |

### Macs: read this first

**The Mac build is not signed with an Apple Developer ID and is not notarized**, so macOS stops it the first time. That is expected, and it takes a minute to get past:

1. Drag **Volt** from the disk image into **Applications**, and double-click it.
2. When macOS says it could not verify Volt, click **Done**.
3. Open **System Settings > Privacy & Security**, scroll to **Security**, and click **Open Anyway** next to Volt. Enter your password or use Touch ID, then click **Open Anyway** once more.

Prefer the Terminal? Files downloaded with `curl` are not quarantined, so no dialog appears at all:

```bash
curl -fL -o ~/Downloads/Volt.dmg https://github.com/LeulAria/volt/releases/download/v0.0.2/volt-stable-0.0.2-darwin-arm64.dmg   # x64 on an Intel Mac
hdiutil attach ~/Downloads/Volt.dmg -nobrowse -quiet && cp -R /Volumes/Volt/Volt.app /Applications/ && hdiutil detach /Volumes/Volt -quiet
xattr -dr com.apple.quarantine /Applications/Volt.app   # only if you downloaded it in a browser
open -a Volt
```

To use Volt from the Terminal, run **Shell Command: Install 'volt' command in PATH** from the command palette, then `volt .` in any folder.

The [macOS install guide](https://github.com/LeulAria/volt/blob/v0.0.2/docs/install/macos.md) has screenshots of each step, the "Volt is damaged" fix, uninstall steps and troubleshooting.

### Windows and Linux

The Windows installers are not code-signed either. When SmartScreen says **Windows protected your PC**, click **More info**, then **Run anyway**. On Linux, `sudo apt install ./volt-stable-0.0.2-linux-x64.deb` or `sudo dnf install ./volt-stable-0.0.2-linux-x64.rpm`. See the [install overview](https://github.com/LeulAria/volt/blob/v0.0.2/docs/install/README.md).

## Known limitations

- On macOS, Volt cannot install updates by itself while it is unsigned. It tells you when a new version is out and opens the download.
- macOS is the platform Volt is developed and tested on. Windows and Linux builds come from CI and have had little testing.
- The agent server, web, mobile, Relay and Govern pieces are early and may change.

Found a problem? [Open an issue](https://github.com/LeulAria/volt/issues/new/choose). For a security problem, follow [SECURITY.md](https://github.com/LeulAria/volt/blob/v0.0.2/SECURITY.md) instead of opening a public issue.
