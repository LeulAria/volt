Volt 0.0.5 is released: commits by the hunk, a model for each multitask, and a Trajectory panel that works with the agent server.

✦ https://github.com/LeulAria/volt

+ split one file across commits, hunk by hunk
+ undo a single hunk from a review diff
+ Review Draft Commits opens at once, with Cancel
+ a model for each multitasked message
+ search every Settings list by column
+ Trajectory panel shows the agent server's runs
+ Agent mode edits again when you ask a question
+ Claude turns close their finished tasks
+ waiting tools are no longer stopped as loops
+ and much more

---

## Highlights

- **Hunk-level draft commits.** The agent can split one file across commits by hunk, and Review Draft Commits opens at once with a live spinner and Cancel.
- **Revert a hunk.** An undo button beside each hunk in a review diff puts it back and saves the file.
- **A model for each multitask.** Start Multitasking's Configure toggle picks the model each picked queued message starts on.
- **Trajectory works with the agent server.** The Trajectory panel shows the model requests of runs in the agent server (the default), and it updates while a reply streams.

## Added

- Start Multitasking has a Configure toggle that picks a model for each picked queued message.
- Generate Draft Commits starts the review right away (spinner, Cancel), and the agent can split one file across commits by hunk. The review is now called Review Draft Commits, with blue checkboxes, header buttons, per-commit diffs and a composer chip.
- An undo button beside each hunk in review diffs reverts that hunk and saves the file.
- Settings lists have a search for each column.

## Changed

- The title bar's panel, files and right panel toggles use one outline icon set at the same size as the other title bar icons.
- The side toolbar's settings button looks like Collapse and shows whenever the toolbar is hovered. It stays while its menu is open.
- The footer update button, the outlined PR Merge button and square Models rows match the rest of Volt. Tab & Prediction no longer shows a sparkle icon.
- Review diffs have brighter line numbers, and Add to Chat from them no longer opens a closed sidebar.

## Fixed

- The Trajectory panel said "No model requests recorded" for every chat while agents ran in the agent server (the default). Windows and the web client now read the agent server's trajectories.
- In Agent mode, a message phrased as a question could not edit files or run commands, so the agent replied that it could only answer. Only Ask and Plan are read-only now.
- Claude turns close their finished tasks before they end, and the Tasks card no longer brings back an older reply's list.
- Waiting tools (`await_commits`, `await_answers`, `terminal_wait` and the others) can repeat without being stopped as a loop. Loop, stall and budget findings a run recovered from stay in the trajectory; the chat shows one only when it ended the run.

## Known limitations

- macOS is the platform Volt is developed and tested on. Windows and Linux builds come from CI and have had little testing.
- The Trajectory panel covers models Volt runs itself. Claude Code, Codex and other external agents keep their own requests, so they don't appear there.

The same list is in the [changelog](https://github.com/LeulAria/volt/blob/v0.0.5/CHANGELOG.md#005---2026-10-31).

## Install

| Your computer | Download |
| --- | --- |
| Mac with Apple silicon (M1 and newer) | `volt-stable-0.0.5-darwin-arm64.dmg` |
| Mac with an Intel chip | `volt-stable-0.0.5-darwin-x64.dmg` |
| Windows (x64, or Arm) | `volt-stable-0.0.5-win32-<arch>-user-setup.exe` |
| Linux | `volt-stable-0.0.5-linux-<arch>.deb`, `.rpm` or `.tar.gz` |

**Already on 0.0.4?** Volt downloads this update by itself: click **Restart to Update** in the title bar.

**Mac:** open the `.dmg`, drag **Volt** onto **Applications** and open it. A chip named *Apple M…* in Apple menu > **About This Mac** means you want the `arm64` file.

**Coming from 0.0.3 or older?** Those builds were not signed, so they cannot install this one by themselves. Download 0.0.5 once and drag it onto Applications, choosing **Replace**. Your settings and chats stay.

**Prefer the Terminal?** One command downloads the right build, checks its SHA-256 against this release and installs it (macOS and Linux):

```bash
curl -fsSL https://raw.githubusercontent.com/LeulAria/VOLT/main/install.sh | bash
```

### Windows and Linux

The Windows installers are not code-signed yet. When SmartScreen says **Windows protected your PC**, click **More info**, then **Run anyway**. On Linux, `sudo apt install ./volt-stable-0.0.5-linux-x64.deb` or `sudo dnf install ./volt-stable-0.0.5-linux-x64.rpm`. See the [install overview](https://github.com/LeulAria/volt/blob/v0.0.5/docs/install/README.md).

Found a problem? [Open an issue](https://github.com/LeulAria/volt/issues/new/choose). For a security problem, follow [SECURITY.md](https://github.com/LeulAria/volt/blob/v0.0.5/SECURITY.md) instead of opening a public issue.
