Volt for Mac is now signed with an Apple Developer ID and notarized, so it opens like any other app and updates itself. This release also brings Agent Resources, Claude's plugin marketplace, a Git Graph, proof that an agent's work is done, and a much lighter app.

## Highlights

- **Signed, notarized and self-updating on Mac.** No more Open Anyway in Privacy & Security. New versions download in the background and install with **Restart to Update**, shown in the title bar.
- **About a third of the memory.** Volt went from about 1.9 GB to about 700 MB and from 16 to 23 processes to 7. Agents, the Tab predictor and the code index now start when you first use them instead of at launch, and the file watcher shares a process, so startup and idle take a fraction of the CPU.
- **New Window in about a tenth of a second.** New Window and Open in New Window used to take about 4 s. Once you have used New Window, Volt keeps the next one loaded out of sight.
- **Agents outside the window.** Agents, terminals and automations run in the agent server, so they keep going when a window closes or reloads.
- **Agent Resources.** One page for every agent's instructions, skills, MCP servers and Volt's own harness settings, across every scope, with Claude's official plugin marketplace built in.
- **Proof of done.** When an agent says it finished, Volt checks the claim against what actually ran after the last edit and shows a receipt under the answer.
- **Git Graph.** A graph tab with filters, an activity strip and agent attribution from commit trailers, plus inline blame on by default.
- **Commit review.** The agent splits your changes into commits you can check, rename and regenerate before Commit, Push or PR.

The full list is in the [changelog](https://github.com/LeulAria/volt/blob/v0.0.4/CHANGELOG.md#004---2026-10-31).

## Install

| Your computer | Download |
| --- | --- |
| Mac with Apple silicon (M1 and newer) | `volt-stable-0.0.4-darwin-arm64.dmg` |
| Mac with an Intel chip | `volt-stable-0.0.4-darwin-x64.dmg` |
| Windows (x64, or Arm) | `volt-stable-0.0.4-win32-<arch>-user-setup.exe` |
| Linux | `volt-stable-0.0.4-linux-<arch>.deb`, `.rpm` or `.tar.gz` |

**Mac:** open the `.dmg`, drag **Volt** onto **Applications** and open it. macOS asks once whether to open an app downloaded from the Internet: click **Open**. A chip named *Apple M…* in Apple menu > **About This Mac** means you want the `arm64` file.

**Coming from 0.0.3 or older?** Those builds were not signed, so they cannot install this one by themselves. Download 0.0.4 once and drag it onto Applications, choosing **Replace**. Your settings and chats stay. From 0.0.4 on, updates install themselves.

**Prefer the Terminal?** One command downloads the right build, checks its SHA-256 against this release and installs it (macOS and Linux):

```bash
curl -fsSL https://raw.githubusercontent.com/LeulAria/VOLT/main/install.sh | bash
```

**Use Volt from the Terminal:** in Volt press <kbd>⇧</kbd><kbd>⌘</kbd><kbd>P</kbd>, run **Shell Command: Install 'volt' command in PATH**, open a new terminal, then `volt .` opens the current folder.

### Windows and Linux

The Windows installers are not code-signed yet. When SmartScreen says **Windows protected your PC**, click **More info**, then **Run anyway**. On Linux, `sudo apt install ./volt-stable-0.0.4-linux-x64.deb` or `sudo dnf install ./volt-stable-0.0.4-linux-x64.rpm`. See the [install overview](https://github.com/LeulAria/volt/blob/v0.0.4/docs/install/README.md).

## Known limitations

- macOS is the platform Volt is developed and tested on. Windows and Linux builds come from CI and have had little testing.
- The agent server, web, mobile, Relay and Govern pieces are early and may change.
