## Highlights

- **100+ agents at once.** Switching chats always shows the chat you picked, with its project, branch, files and terminals. With 110 agents streaming, the window gets 27 times less transcript traffic and a chat's transcript arrives in 30 ms instead of 311 ms (median).
- **Automations calendar and Workflows.** List, Day, Week and Month views you can schedule from, every-few-minutes schedules, and a visual Workflows builder with YAML, templates and run history.
- **Run and debug in the agent window.** Run rows for your project's scripts and launch configs, a device picker, the debug toolbar, and browser DevTools docked under the page.
- **Volt in the browser.** The browser client is now the real workbench served by the agent server, with a sign-in page and device pairing.
- **Pull Requests page.** A full-page view with search, filters and grouping, and merged pull requests show as merged within seconds.
- **Remote Control.** Add Device pairs a phone or browser over the same Wi-Fi, Tailscale, a Cloudflare Tunnel or an SSH tunnel, with a QR code or an 8-character code.
- **Computer use everywhere.** The `desktop_*` tools run on macOS, Windows and Linux, read windows with about half the tokens, and can draw.
- **A new release notes page.** The version drawn as a blueprint, a short summary, then every detail.

## Performance

| With 110 agents streaming | 0.0.5 | 0.0.6 |
| --- | ---: | ---: |
| Transcript traffic to the window | 675 KB/s | 25 KB/s |
| Updates to the window | 485/s | 98/s |
| Agent server CPU | 16.8% | 11.9% |
| Wait for a chat's transcript on switch (median / p90) | 311 / 1,126 ms | 30 / 471 ms |

Measured on one dev instance with 110 chats streaming from test agents, the same chats back to back. The agent server also starts warm in about 0.35 s instead of 0.6 to 1.2 s, and computer use reads a window in half the tokens.

## Added

**Agents and chats**
- Chats nobody looks at update once a second; the chats on screen update every 50 ms. Updates are sent as small edits, and a reconnect reopens chats four at a time, the one on screen first.
- Titles say what the chat's task is, a vague first message is titled again from the first two messages, and the title bar shows six words. Chats on Cursor, Grok or OpenCode get their title from another signed-in provider.
- Each agent tab has a ... menu with Open in New Window, Rename and Archive.
- Drag chats into your own order (Sort > Manual). Draft now sits above Pinned.
- Watched tasks: `task_watch` runs a long build and gives the agent control back. On a failure Volt wakes the agent, runs the command again after its fix, and stops after 3 identical failures, 5 attempts or 2 hours. A live card shows each watch.
- Queue changes show in the card at once and keep their order; on the agent server, a prompt sent to an idle chat shows as its turn right away.
- Recent projects under a new chat's composer (Cmd+1 to Cmd+3), including folders Claude Code has worked in.
- New project asks where the project goes, and the folder picker looks like the Explorer, with file icons and files listed dimmed.

**Automations and Workflows**
- List, Day, Week and Month views. Click an empty time to schedule a new automation, a template, or another time for an existing one. A Filter menu, keyboard navigation and a Next Run column.
- One-time schedules, "Every few minutes" (1 minute to 12 hours) and cron presets.
- The instructions box works like the composer: voice, `/` skills, `@` tools, the model picker and a Workflow picker. A `/skill` loads that skill when the run starts. Cmd+S saves.
- Workflows: a visual node builder with a minimap, node inspector, YAML tab, undo and revision history; an engine that checks, simulates, retries and cancels; a template gallery and an executions panel. A pasted workflow lists the exact commands it would run before you accept it.
- 30 more automation templates, in new Docs & Release, Team Updates and Monitoring categories.

**Run, debug and the browser**
- Run rows in the chat's side toolbar for npm, pnpm and yarn scripts, Flutter, Expo, React Native, Django, Go, Cargo and `launch.json`, plus "Let Agent Debug and Run the App".
- A device picker for Flutter, React Native and Expo, extension status bar items in the side toolbar, and the debug toolbar under Run.
- Local addresses from runs and debug sessions open in Volt's browser, and DevTools dock under the page.
- Browser annotations wait in the open chat's composer and stay on the page as numbered pins after sending.

**Git and pull requests**
- A full-page Pull Requests view with search, a repository menu, filter chips and a saved filter menu (grouping, status, checks, review, author, label, size, Has Conflicts, Linked to Chats).
- Suggest branch names: four AI names for a chat's worktree branch; Confirm renames it.
- PR Summary lists the newest commits and shows checks as a list.

**Devices and Remote Control**
- Add Device in Settings > Devices: Same Wi-Fi, Tailscale, Cloudflare Tunnel or SSH Tunnel, each with its checklist, then a QR code or an 8-character code. Addresses stay blurred until hovered.
- Device previews in 3D for every iPhone, iPad and Android phone, tablet and foldable, with a controls rail. With the right panel closed the running device floats over the chat, and several devices can be open as tabs.

**Web and mobile**
- The browser client is the real workbench served by the agent server, with a sign-in page.
- Mobile: a Pull Requests tab, adding a project by browsing folders, tablet and foldable layouts, a bundled diff viewer, the desktop's file icons, and iOS 27 support.
- The Android and iOS apps are built by the release workflows and attached to the release.

**Computer use**
- One protocol on macOS, Windows (UI Automation) and Linux (AT-SPI); `volt.computerUse.enabled` turns it off.
- `draw` takes lines, shapes, arcs, stars and SVG paths in one step; also `drag`, `hover`, clipboard paste and screenshots.
- Actions wait for the app's own change events, and snapshots are about half the size.

## Changed

- Agents open Review Draft Commits only when you ask for draft commits or use `/draft-commit`; "Commit and open a PR" just commits.
- New Agent always opens a fresh chat (`volt.agent.composer.restoreUnsentDraft` brings back the old behaviour).
- Quick pick lists have 26px edge-to-edge rows, and Volt submenus open beside their parent menu.
- Help > Show Release Notes opens this version's notes in Volt.
- Pull requests now run CI: lint, type checks, unit tests, the app builds and a free AI review.

## Fixed

- With 10+ agents running, switching chats could show one chat's transcript under another's highlight, and the branch pill could keep the previous project's branch.
- Replies to turns started by automations, agent-launched threads, run groups and `/compact` were lost when the agent server restarted.
- The Trajectory panel was empty for Claude Code, Codex and Cursor chats.
- A merged pull request could show as Open for over a minute.
- Commit review showed only the first line of a failing pre-commit hook; it now shows the real reason and offers Commit Without Hooks.
- A chat could keep saying Working after its turn ended.
- Source Control showed "spawn git ENOENT" when a chat's worktree folder was missing, and an unsent worktree chat showed the main checkout's changes.
- Keep or Undo on a hunk was lost if the window reloaded within half a second.
- Inline comment edits whose reply wrapped the code in a fence after a lead-in line applied the whole reply.
- Mobile Connect rejected addresses with spaces or commas, and pasted pairing links.

## Known limitations

- macOS is the platform Volt is developed and tested on. Windows and Linux builds come from CI and have had little testing; computer use on Windows has not yet run on a real Windows machine.
- The iOS app is a simulator build (it runs in the iOS Simulator on Apple silicon) until iOS release signing is set up. The Android app is signed for release, with an `.aab` for Google Play.

The full list is in the [changelog](https://github.com/LeulAria/volt/blob/v0.0.6/CHANGELOG.md#006---2026-11-04).

## Install

| Your computer | Download |
| --- | --- |
| Mac with Apple silicon (M1 and newer) | `volt-stable-0.0.6-darwin-arm64.dmg` |
| Mac with an Intel chip | `volt-stable-0.0.6-darwin-x64.dmg` |
| Windows (x64, or Arm) | `volt-stable-0.0.6-win32-<arch>-user-setup.exe` |
| Linux | `volt-stable-0.0.6-linux-<arch>.deb`, `.rpm` or `.tar.gz` |

**Already on 0.0.4 or 0.0.5?** Volt downloads this update by itself: click **Restart to Update** in the title bar.

**Mac:** open the `.dmg`, drag **Volt** onto **Applications** and open it. A chip named *Apple M…* in Apple menu > **About This Mac** means you want the `arm64` file.

**Coming from 0.0.3 or older?** Those builds were not signed, so they cannot install this one by themselves. Download 0.0.6 once and drag it onto Applications, choosing **Replace**. Your settings and chats stay.

**Prefer the Terminal?** One command downloads the right build, checks its SHA-256 against this release and installs it (macOS and Linux):

```bash
curl -fsSL https://raw.githubusercontent.com/LeulAria/VOLT/main/install.sh | bash
```

### Windows and Linux

The Windows installers are not code-signed yet. When SmartScreen says **Windows protected your PC**, click **More info**, then **Run anyway**. On Linux, `sudo apt install ./volt-stable-0.0.6-linux-x64.deb` or `sudo dnf install ./volt-stable-0.0.6-linux-x64.rpm`. See the [install overview](https://github.com/LeulAria/volt/blob/v0.0.6/docs/install/README.md).
