This release brings Scratch, a whiteboard agents draw on; budgets and handoff contracts for subagents; agents that keep out of a browser tab you are using; windows with their own chats; and the web and mobile apps catching up with the desktop.

## Highlights

- **Scratch, a whiteboard for you and your agents.** Sketch, write and diagram on an infinite board, then ask an agent about what you selected. It draws its answer back as a diagram beside yours, and its chat opens in a dock at the bottom of the board.
- **Subagents with budgets and contracts.** Each delegated task carries a goal, constraints, the files it owns and when it is done. A request has a spending cap, tasks can wait for each other, and a task can fall back to another model.
- **Agents keep out of your browser tab.** If you are typing, commenting or designing in a tab, an agent opens its own *Agent* tab instead of taking yours over.
- **An empty right panel lists what can open there.** File, Terminal, Browser, Device, Changes, Scratch, Canvas, Automations and New Side Chat, with their shortcuts.
- **A New Window with its own chats.** A second window lists only the chats and projects started in it and hands them back when it closes.
- **Web and mobile catch up.** The mobile app is laid out like the GitHub app, with source control and pull requests, and the browser workbench fits phones, tablets and touch screens.

The full list is in the [changelog](https://github.com/LeulAria/volt/blob/v0.0.3/CHANGELOG.md#003---2026-10-25).

## Install

| Your computer | Download |
| --- | --- |
| Mac with Apple silicon (M1 and newer) | `volt-stable-0.0.3-darwin-arm64.dmg` |
| Mac with an Intel chip | `volt-stable-0.0.3-darwin-x64.dmg` |
| Windows (x64, or Arm) | `volt-stable-0.0.3-win32-<arch>-user-setup.exe` |
| Linux | `volt-stable-0.0.3-linux-<arch>.deb`, `.rpm` or `.tar.gz` |

### Macs: read this first

**The Mac build is not signed with an Apple Developer ID and is not notarized**, so macOS stops it the first time. That is expected, and the steps below take about a minute. You do them once.

1. **Find the download** and open the `.dmg`. A chip named *Apple M…* in Apple menu > **About This Mac** means you want the `arm64` file.

   <img src="https://raw.githubusercontent.com/LeulAria/volt/v0.0.3/docs/install/images/01-download.jpg" alt="The downloaded disk image selected in Finder" width="560" />

2. **Open the disk image.** A window opens with **Volt** and an **Applications** shortcut.

   <img src="https://raw.githubusercontent.com/LeulAria/volt/v0.0.3/docs/install/images/02-open-dmg.jpg" alt="The Volt disk image window" width="480" />

3. **Drag Volt onto Applications**, then eject the disk image.

   <img src="https://raw.githubusercontent.com/LeulAria/volt/v0.0.3/docs/install/images/03-drag-to-applications.jpg" alt="Dragging Volt onto the Applications shortcut" width="480" />

4. **Open Volt** from Applications, Launchpad or Spotlight.

   <img src="https://raw.githubusercontent.com/LeulAria/volt/v0.0.3/docs/install/images/04-open-volt.jpg" alt="Spotlight showing the Volt app" width="560" />

5. macOS says **"Volt" Not Opened**. Click **Done**. (The **?** opens Apple's help page, the quickest way to the next step.)

   <img src="https://raw.githubusercontent.com/LeulAria/volt/v0.0.3/docs/install/images/05-not-opened.jpg" alt="The Volt Not Opened dialog" width="320" />

6. **Open the Privacy & Security settings.** On Apple's help page click *Open Privacy & Security settings for me*, or open **System Settings** yourself.

   <img src="https://raw.githubusercontent.com/LeulAria/volt/v0.0.3/docs/install/images/06-help-link.jpg" alt="Apple's help page with the settings link highlighted" width="560" />

7. **Choose Privacy & Security** in the sidebar, or search for it.

   <img src="https://raw.githubusercontent.com/LeulAria/volt/v0.0.3/docs/install/images/07-privacy-and-security.jpg" alt="System Settings with Privacy and Security highlighted" width="560" />

8. **Scroll down to Security and click Open Anyway** next to *"Volt" was blocked to protect your Mac*. The button shows for about an hour after a blocked attempt, so if it is missing, open Volt again first.

   <img src="https://raw.githubusercontent.com/LeulAria/volt/v0.0.3/docs/install/images/08-open-anyway.jpg" alt="The Open Anyway button in Privacy and Security" width="560" />

9. **Click Open Anyway again** in the *Open "Volt"?* dialog. The blue button is **Move to Trash**, so do not press Return.

   <img src="https://raw.githubusercontent.com/LeulAria/volt/v0.0.3/docs/install/images/09-confirm-open.jpg" alt="The Open Volt dialog with Open Anyway highlighted" width="560" />

10. **Verify it is you** with Touch ID, or click **Use Password…**.

   <img src="https://raw.githubusercontent.com/LeulAria/volt/v0.0.3/docs/install/images/10-authenticate.jpg" alt="The Touch ID or password prompt" width="420" />

11. **Volt opens.** If macOS asks about access to a folder such as Documents, click **Allow**. Volt opens normally from now on.

   <img src="https://raw.githubusercontent.com/LeulAria/volt/v0.0.3/docs/install/images/11-first-launch.jpg" alt="Volt's first window" width="560" />

**Prefer the Terminal?** One command downloads the right build for your computer, checks its SHA-256 against this release and installs it, with no `sudo` and no dialogs (macOS and Linux):

```bash
curl -fsSL https://raw.githubusercontent.com/LeulAria/VOLT/main/install.sh | bash
```

Or by hand on a Mac (`x64` on an Intel Mac):

```bash
curl -fL -o ~/Downloads/Volt.dmg https://github.com/LeulAria/volt/releases/download/v0.0.3/volt-stable-0.0.3-darwin-arm64.dmg
hdiutil attach ~/Downloads/Volt.dmg -nobrowse -quiet && cp -R /Volumes/Volt/Volt.app /Applications/ && hdiutil detach /Volumes/Volt -quiet
open -a Volt
```

**Use Volt from the Terminal:** in Volt press <kbd>⇧</kbd><kbd>⌘</kbd><kbd>P</kbd>, run **Shell Command: Install 'volt' command in PATH**, open a new terminal, then `volt .` opens the current folder.

If you see *"Volt is damaged and can't be opened"*, the app is fine: run `xattr -dr com.apple.quarantine /Applications/Volt.app` and open it again.
The [macOS install guide](https://github.com/LeulAria/volt/blob/v0.0.3/docs/install/macos.md) has the same steps plus uninstall and troubleshooting, and the website has it at [volt.leularia.com/docs/install](https://volt.leularia.com/docs/install).

### Windows and Linux

The Windows installers are not code-signed either. When SmartScreen says **Windows protected your PC**, click **More info**, then **Run anyway**. On Linux, `sudo apt install ./volt-stable-0.0.3-linux-x64.deb` or `sudo dnf install ./volt-stable-0.0.3-linux-x64.rpm`. See the [install overview](https://github.com/LeulAria/volt/blob/v0.0.3/docs/install/README.md).

## Known limitations

- On macOS, Volt cannot install updates by itself while it is unsigned. It tells you when a new version is out and opens the download.
- macOS is the platform Volt is developed and tested on. Windows and Linux builds come from CI and have had little testing.
- The agent server, web, mobile, Relay and Govern pieces are early and may change.

Found a problem? [Open an issue](https://github.com/LeulAria/volt/issues/new/choose). For a security problem, follow [SECURITY.md](https://github.com/LeulAria/volt/blob/v0.0.3/SECURITY.md) instead of opening a public issue.
